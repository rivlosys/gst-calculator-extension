# GST/HST Calculator Canada – Chrome Extension

A fast and simple GST, HST, PST, and QST calculator for Canada.

## Features
- Calculate tax instantly
- Auto-detect prices on active webpage
- Add or remove tax
- Business mode with ITC
- Export CSV

## Privacy
This extension does not collect or transmit user data.
All processing happens locally.
